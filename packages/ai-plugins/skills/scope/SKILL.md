# 知书范围技能（scope）

版本：1

## 使用条件

- 内部助手与公开站点会话均注册；公开站点的范围只能是批准资料的子集。

## 规则

1. 将控件或自然语言范围意图解析为 all/workspaces/documents 选择，提交 set_conversation_scope。
2. 服务器按当前授权求交并持久化，推进 contextRevision；范围变化不授予新权限。
3. 范围变化后旧 Run 停止交付，下一轮按新上下文重建允许的历史与证据。
4. 不声称已访问范围外资料；可见空间不等于可检索全部正文。

## 输入与输出

- 输入：范围意图（空间/文档/全部）。
- 输出：服务器验证后的会话范围与新的 contextRevision。
