# 知书检索技能（rag）

版本：1

## 使用条件

- 仅当回答或写作需要平台内文档事实时执行。
- 检索范围由服务端根据当前授权解析；模型不得指定或扩大范围。

## 流程约束

1. 先取得服务端验证的范围引用（scopeRef 与 contextRevision）。
2. 检索按有界预算执行：单次问题、固定候选上限、证据条目与 token 上限。
3. 每条证据必须由服务端登记为 evidence artifact 后才能被引用；引用只能使用已登记的 evidenceId。
4. quote 必须逐字来自登记的证据区间；不能编造来源、URL 或标题。
5. 检索结果为空时返回“资料不足”，不得用模型记忆补写事实，也不得访问互联网。
6. 交付前复核当前授权与持久化版本；复核失败按撤权处理，不展示旧证据。

## 输入与输出

- 输入：问题文本、可信范围引用、有界预算。
- 输出：evidence artifact（sources + items）、来源版本、引用候选。
