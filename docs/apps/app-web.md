# app-web 设计规划

普通快照与协同文档共用 `-document-asset-services.ts` 提供的文档级宿主适配器：上传会话、幂等重试、取消清理和短时 URL 解析从同一处实现；正文只写稳定 assetId 与媒体信息，授权 URL 留在 DOM 状态中。

历史版本预览复用只读 EditorProvider，并挂载 `EditorCodeBlockView`；语言选择禁用，代码复制仍可用。

状态：M2 部分实现。对应 `apps/app-web`；[返回文档地图](../README.md)。本应用组合六个 packages，提供独立文档产品与企业知识平台界面。新建文档时可选择实时协同或普通快照模式。当前已实现 `/documents` 工作台、文档标题/元数据页、基于 app-server OpenAPI 的生成客户端，以及连接 app-server/Hocuspocus 的正文协同编辑器。协同模式下编辑页分别展示连接、同步和 durable ack 持久化状态；普通模式使用独立 JSON 快照编辑器和显式修订保存，不会在打开时自动升级协同模式；文档工作台列表分别显示普通快照修订号与协同持久化序号。协同与普通快照编辑器均提供自动/命名版本列表、只读历史正文与恢复入口；快照恢复递增 snapshotRevision，协同文档恢复到新 generation。宿主已将上传、正文结构操作与临时授权图片读取接通。浏览器已验中文编辑、服务端确认、刷新后重开，以及协同版本列表、历史差异预览、自动版本间隔和保留策略、确认恢复；消费样例已验查找的跨 Mark 命中、大小写不敏感、循环导航和定位。普通快照版本迁移 0017 已应用到项目独立 PostgreSQL；本地浏览器已验证普通命名/自动版本、差异预览、确认恢复和重开，并将标准历史版本恢复到新协同 generation；历史附件引用保留和硬删除后的对象清理已用临时本地 MinIO/PostgreSQL 验收。图片上传后可从签名 URL 读取；错误 MIME 拒绝后同一上传会话重试成功，取消操作成功。Chromium 浏览器验收还注入了存储首次拒绝，确认失败后显示重试/取消，重试复用同一会话并插入图片、取消则清除未完成会话。该次故障注入使用本机 S3 协议桩，仅验证应用状态转换；生产对象存储 provider 尚未配置。仓库提供通过 `pnpm compose:up:storage` 启动的单节点 Garage 作为本地 S3 端点；它只用于开发且没有生产级数据冗余，Garage 的实存储往返及普通/协同编辑器上传保存重开仍待验收。文档页现在可导出服务端已保存版本的 JSON/HTML/纯文本，也可把知书 JSON 包、基础 HTML 和纯文本导入为新文档，并在降级时显示损失说明。所有者可在文档页按主体 ID 查看、授予、更新和撤销 ACL；本地 Chromium 已验授权、更新、有效能力展示与撤销。主体目录、邮件邀请和委托授权仍未实现；附件管理面板和持久化大任务状态仍待实现。M1 嵌入编辑器目标支持桌面 Chrome/Edge/Firefox/macOS Safari 当前和上一稳定主版本，JSON Schema v1 无损往返；窄屏基础编辑在 M2 定义。

协同与普通快照编辑器均使用 `EditorShell`；选中图片后可编辑替代文本、宽度和高度。消费样例已在 Chromium 验证合法属性写入 DOM/JSON、非法尺寸拒绝和 320px 无横向溢出；PDF 正文附件可由宿主解析短时授权 URL。Chromium 已验证 PDF 协同插入获得 durable ack，并从本机 MinIO 的短时授权 URL 读回原字节；图片属性在协同会话中的 durable ack 仍待专项验收。

## 1. 产品职责与现有基础

沿用 React、Vite、TypeScript、TanStack Router/Query、React Hook Form、Zod、Orval 及现有基础 UI。`orval.config.ts` 从 `apps/app-server/openapi.json` 生成客户端，根级 `pnpm check` 会运行前端类型检查、构建与生成漂移检查。

已实现的 WEB-01 工作台将 view、搜索词、排序、方向和 offset 保存在 URL；支持最近/我的/全部/收藏/归档/回收站视图、创建、标题查询、服务端排序分页、收藏切换、归档、移入回收站、恢复与永久删除确认。回收站列表显示移入时间，恢复和永久删除按钮按 owner 能力禁用，并显示处理中状态；服务端仍复核授权。自动保留期限和过期清理策略尚未定义，当前不自动永久删除回收站内容。列表接口仅返回 `canManage` 能力布尔值，不向浏览器暴露创建者身份。开发模式可通过 mock 登录取得短期 bearer token，token 仅保存在当前页面内存，刷新后需重新登录。生产身份仍由宿主接入。

支持两个产品配置：独立文档入口只需要文档、身份、授权和协同服务；企业平台配置增加空间、知识库、AI、评论与管理。页面是否出现由服务端返回的可用能力和当前用户权限共同决定，隐藏菜单不代表后端已经授权。

文档页的编辑/阅读模式是按文档保存的本地界面偏好，不改变普通/协同内容模式或服务端权限。普通和协同 Provider 通过即时 `editable` 切换，阅读模式隐藏编辑工具并保留查找、大纲和业务分享/导出；协同状态错误、拒绝或服务端只读仍会覆盖本地编辑偏好。Chromium 已在实际协同页验证切换时工具显隐及会话不重建；普通模式、服务端只读用户和刷新恢复仍待回归。标题 Emoji、彩色标签、作者与相关文档字段尚未接入当前 API。

### 工作台视觉规格

syncscribe 的桌面基线为 288px 展开导航、56px 收起导航和约 288px 右侧大纲；中间画布根据剩余宽度伸缩，正文目标最大宽度 896px。知书沿用该尺寸作为桌面起点，中小屏将左右栏改为可关闭抽屉。页面使用 Slate 50/100 画布与白色面板，品牌强调采用 Indigo 600；暗色使用 Slate 900/950。文档编辑页正文使用 16px 字号、1.75 行高，工作台界面文字以 14px 为默认值。

颜色、边界、圆角、阴影与焦点态已由全局语义变量提供，并映射到 `--zhishu-ui-*`；编辑器包保留独立默认值，可由单个实例覆盖。app-shell 已提供亮色、暗色和跟随系统选项并保存偏好；桌面导航支持 288px/56px 展开收起，移动导航使用 Dialog 抽屉，关闭后焦点返回触发按钮。普通与协同编辑器现由应用层组合独立的大纲和详情栏：桌面详情宽 288px、可收起；窄屏由编辑器页头按钮打开 Dialog 抽屉。面板展示正文大纲、模式、创建/更新时间和真实的管理能力。大纲高亮按当前编辑器 heading Block 与最近可滚动祖先更新；消费样例滚动至文档后段时已观察到当前标题切换。当前 API 没有作者、标签和相关文档字段；重复标题、远端改动、路由中的滚动行为及详情抽屉焦点恢复仍需专项验收。

## 4. 编辑页面组合

```text
DocumentPage
  DocumentHeader             标题、只读原因、分享、业务动作
  DocumentStatus             连接、持久化回执、版本与索引状态
  EditorProvider             editor-react 生命周期与宿主服务
      EditorShell              editor-ui 默认外观/菜单、统计页脚
      EditorSurface          editor-core + 可选协同绑定
  OutlinePanel               当前内容大纲
  VersionPanel               业务版本与只读预览
  CommentsPanel              服务端评论 + 编辑器锚点
  AuthoringPanel             ai-bridge 任务与提案
  KnowledgePanel             检索/问答与来源
```

版本预览与当前正文使用不同的实例/会话配置；预览不得连接当前可写 Y.Doc。历史正文通过独立只读 `EditorProvider` 和相同 `EditorShell` 呈现，也可以切换到 Block 差异视图。历史预览正文使用有界的独立滚动面板，定位长文档标题时保留大纲和统计栏。普通/协同编辑器与历史预览均展示包级统计，普通保存摘要仍由宿主插槽提供。多个侧栏同时打开时规定主次与宽度，窄屏改为抽屉；侧栏关闭后恢复编辑焦点。

## 5. 关键用户流程

### 新建与首次打开

用户选择空白/模板 → 服务端创建文档并初始化一次内容 → 跳转稳定 documentId → 请求会话与权限 → 等待协同状态加载 → 展示编辑器。创建按钮有请求中状态；工作台对相同创建参数复用 `Idempotency-Key`，失败保留标题/模板选择，API 在 24 小时内重放原创建响应；其他写路由幂等待接入。

首次打开区分不存在、无权限、回收站、Schema 不兼容和服务不可用。权限错误可以使用服务端统一的资源不可见语义；不能用失败的内容请求初始化空文档。

### 编辑、保存与离开

正文由 core/collaboration 管理，页面分别展示连接和持久化进度。标题与其他元数据走带 metadataRevision 的 API，不与正文全文保存混用。应用内路由切换或退出登录遇到未确认修改时，提示用户继续编辑、放弃修改，或下载符合 `zhishu.document` v1 的 JSON 草稿后离开；浏览器刷新/关闭使用原生离开提示。Playwright 本地 Chromium 已验普通快照路由提示、继续编辑、导出后离开，导出文件格式及正文正确；刷新触发原生提示，取消后草稿仍在当前页面。协同模式断网产生 pending 更新时，路由切换和登出均显示三种处理选项；继续编辑后恢复联网，更新收到 durable ack 并保存至序号 3。草稿不包含图片文件。关闭浏览器前的异步请求不作为可靠保存手段。

### 版本与恢复

用户选择历史版本 → 只读查看/对比 → 明确恢复会形成新当前代次 → 服务端恢复并返回新 generation → 页面重建会话。协同恢复及普通快照恢复均已在本地浏览器确认；普通模式完成命名/自动版本、差异预览、确认恢复后修订递增及重新登录重开验收。两标签页并发保存验收确认，旧 `snapshotRevision` 写入显示冲突并阻止覆盖；重载后保留先提交内容。普通快照升级为协同时，初始化期间如有新的 durable ack，页面会把最新序号带入版本操作；本地浏览器已把标准历史版本恢复进协同文档的新 generation，并确认恢复正文正确。standard 历史附件引用保留、当前引用清空后的保留，以及文档永久删除后的对象清理均已在临时 MinIO/PostgreSQL 验收。版本差异通过只读历史内容 API 读取，不另建可写 Y.Doc。其他协作者收到变化提示；当前未保存内容可保留为副本，不能静默丢弃。评论锚点无法映射时显示原版本及失效状态。

### 上传与导入

选择/粘贴文件 → 上传服务返回进度 → 服务端确认可引用资产 → core 按有效锚点插入。失败在对应位置提供重试/取消；取消或目标被删除时不插入正文。导入先预览格式兼容报告，再创建文档或执行明确插入，不直接覆盖当前协同内容。

文档页的传输操作允许导出服务端已保存的 JSON 包、独立 HTML、Markdown（CommonMark/GFM）或纯文本，并导入为新文档。转换会在继续前显示格式损失；图片和 PDF 资产不能跨文档导入。打印/PDF 先通过现有导出权限读取已保存正文，在独立窗口只呈现正文与标题，私有附件使用文字占位，代码换行、表格重复表头并控制分页。该入口不导出未确认的本地修改，也不提供异步大任务队列或任务状态。

`features/knowledge` 管理真实工作区切换、递归目录、子页创建、原位重命名、删除、拖拽与键盘可替代移动。目录冲突保留当前输入/移动目标，允许重新加载目录后重试。面包屑根据当前文档工作区及可见父链生成；工作区偏好按租户/身份隔离。全局 Ctrl/Cmd+K 搜索支持标题与正文片段、可见祖先路径、关键词标记、全工作区筛选、方向键与 Enter；新输入和关闭弹窗取消查询，Escape 回到之前焦点。编辑器选中文本时快捷键优先打开链接操作，输入法组合期间不接管按键。

文档信息面板可编辑单个 Emoji 和最多 12 个彩色标签，真实创建者/时间及标签也显示在详情栏。PATCH 携带 metadataRevision，冲突保留输入并刷新基础修订。阅读模式保留查找、大纲和授权分享/导出，切换不重建编辑器；服务端写权限独立生效。任务完成动效由个人开关控制，默认关闭，并遵循减少动画偏好。

### 离线缓存与草稿恢复

`features/offline` 用 IndexedDB 保存最近授权读取的目录、元信息、正文与草稿，按 API、租户、身份、工作区、文档、generation 和内容格式隔离。普通草稿携带基础 snapshotRevision 与标签页标识；协同检查点保存正文投影、基础结构修订和未收到 durable ack 的原生 Yjs 更新。凭据及附件授权 URL 不写入缓存。

生产构建生成仅缓存公共页面资源的 Service Worker，需 HTTPS 或 localhost；开发构建可设置 `VITE_ENABLE_OFFLINE=true` 验证。资源完整安装后启用新缓存，保留最近两份页面资源；API 不进入 Service Worker 缓存。未缓存文档显示不可用范围，不能把读取失败当空正文。

断网刷新允许本机恢复上次已校验账户的缓存资料，显示离线/权限待校验提示，不以缓存身份签发网络写入。联网后重新登录并检查权限。普通文档确认恢复草稿后显式保存；保存前重新读服务器修订，版本/代次/权限变化则保留可导出草稿。协同缓存离线刷新为只读；新会话校验权限、generation、格式和结构修订一致后重放未确认原生更新，等待 durable ack 后清除待确认记录；不一致则保留副本，禁止将旧整文 JSON 灌入当前会话。

401 清理授权响应和缓存账户，403/404 清理受影响文档及包含它的目录/列表；未确认草稿保留供导出。退出前处理未确认修改并清除该身份缓存。IndexedDB 不可用、空间不足或页面缓存安装失败均显示提示与导出入口；本机缓存成功和服务器保存成功分别表达。

### 知识问答与 AI 创作

问答选择的知识域由服务端验证，UI 展示来源文档、版本和片段。没有可用证据时明确说明；引用打开再次请求权限。流中断保留已展示文本并标记不完整，不把部分答案当完成结果。

编辑器 AI 动作捕获当前目标 → ai-bridge 管理流与草稿 → 用户预览并接受 → core 应用 → 等待持久化回执。知识问答结果需要用户选择“插入新块”才能成为正文，不自动覆盖当前选区。

### 评论与提及

评论正文、线程状态和成员权限由服务端管理；编辑器只呈现锚点装饰。新评论失败保留草稿；目标删除仍可查看讨论并注明上下文丢失。提及候选仅来自可见成员，通知收件人仍需具备目标文档访问权。

## 6. 状态归属与工程结构

| 状态                               | owner                                      | 约束                                             |
| ---------------------------------- | ------------------------------------------ | ------------------------------------------------ |
| 路由、列表筛选、分页               | TanStack Router URL                        | 刷新/分享后可恢复，失效条件可回退                |
| 文档元数据、空间、评论、版本、任务 | TanStack Query / 生成客户端                | 查询键包含租户/用户/资源上下文；变更后按范围失效 |
| 表单、评论草稿、设置草稿           | React Hook Form + 页面局部状态             | 后台刷新不覆盖未提交输入                         |
| 正文与选区                         | core / collaboration                       | 不复制进 Query、Zustand 或表单全文字段           |
| AI 草稿与任务                      | ai-bridge                                  | 页面仅订阅投影，组件卸载传播取消                 |
| 侧栏、弹窗、密度                   | 本地 React state；确有跨页共享再用 Zustand | 不把远端数据搬入全局 store                       |

按 `features/documents / spaces / knowledge / authoring / comments / settings` 聚合页面、表单和 query 组合；路由只组装 feature。`api/generated` 来自 app-server OpenAPI，不手写平行 API DTO；WebSocket 与 SSE 使用对应协议适配器，不强行套进普通 JSON mutation。

## 7. 完整状态与权限反馈

所有页面覆盖 loading、empty、error/retry、无权限、只读、请求中、成功和部分失败。列表删除失败保留原条目，移动操作冲突提供重新加载，后台索引失败显示原因/重试入口，避免仅弹出短暂 toast。

退出/切换账户时断开会话、取消请求并清除该身份的缓存；离线副本依部署策略处理。分享、导出、管理成员等入口遵守服务端 action 能力，并在提交时接受服务端再次拒绝。

破坏性操作、历史版本恢复、格式转换损失与放弃未保存正文均通过应用 `ConfirmDialog` 呈现对象、影响和进行中状态；失败会保留确认内容并显示错误。普通快照正文重载会明确说明本地修改将被丢弃。浏览器刷新/关闭时继续由应用离开拦截和原生浏览器提示处理。

业务只读与浏览器网络故障分别表达。审批中限制哪些操作由服务端策略给出；界面不能自行把“看不到编辑按钮”解释为“内容受到保护”。

## 8. 质量与交付

独立文档配置下不请求知识库/模型初始化接口，不出现配置缺失报错；完整平台配置通过能力发现增加入口。最低演示链路为创建 → 双端协作 → 保存 → 关闭重开 → 恢复版本。当前浏览器验收在本地独立前后端和 PostgreSQL 上通过：编辑中文正文后 durableSeq 从 2 增至 24，刷新并重新登录后正文及服务端序号均恢复；单独的版本验收覆盖命名版本元数据、旧/当前 Block 差异和确认恢复后的新 generation。生产身份接入仍未覆盖。

验收覆盖桌面/窄屏、键盘/输入法、多标签页、慢网/断网、长标题/长文档、附件失败、权限变更、AI 冲突和引用失效。性能目标引用文档地图，不在此复制另一套指标。M3 需从有授权的知识来源走通索引、问答、引用查看与 AI 插入的完整路径。
